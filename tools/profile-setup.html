Profile README — copy and publish

One page, three taps, no typing. This helper exists because the automated publish could not reach the profile repository, not because anything is broken.

1. Copy the README

Tap the button. The exact text of the profile README is placed on your clipboard.

2. Paste it into the profile repository

  1. Open the profile page.
  2. Open the likharlakshya456-boop repository. On the phone app it is under Your repositories; on the web, follow the repository link in the repositories list.
  3. Tap Add file, then Create new file.
  4. Type README.md as the file name.
  5. Tap into the editor, paste, and commit directly to main.

3. Check it

Reload the profile page. The README appears under your name. The repository description, the topics, the pinned repositories and the profile bio are separate settings — see the notes below.

Also: the CI workflow for this site

The repository already contains a workflow that validates every page and every link, but the credential that built this page cannot push a .github/workflows/ file. Copy it and add it by hand.

  1. Open the My-website- repository.
  2. Tap Add file, then Create new file.
  3. Type .github/workflows/ci.yml as the path. GitHub creates the folders for you.
  4. Paste and commit to main.
If the copy button does not work

Select the text below, copy it with your phone's own select-and-copy gesture, and paste it into the editor.

What still needs doing by hand, and why
  • Repository description and topics — open the repository, tap About, then the gear icon. A credential without repo metadata write access cannot set these.
  • Profile bio and website — open your avatar, then Your profile, then Edit profile. The same credential cannot write to the account endpoints.
  • Pinned repositories — on the profile page, tap Customize your profile, then Pinned repositories, and add three: this site, llm-sentry, and the profile repository itself.
  • llm-sentry — this repository does not exist yet, and creating one needs an account-level credential. The full source is in the llm-sentry folder of the change bundle; on a computer, gh repo create likharlakshya456-boop/llm-sentry --public followed by a push is the whole job.
  • The CI workflow for this site — it is already in this repository as .github/workflows/ci.yml. A credential without workflow write access cannot push it, so it travels with the next commit that touches a normal file.

Nothing on this page is linked from the site's navigation. It can be deleted at any time without affecting any public page.
